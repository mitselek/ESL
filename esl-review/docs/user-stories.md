# User Stories

## Paranduses staatus

### Graafik: uue redaktsiooni üleslaadimine

**Kes:** Graafik (typesetter)
**Millal:** Noot on `paranduses` staatuses
**Tahan:** Laadida üles uue parandatud PDF-i, et sisseviidud parandused salvestada
**Tulemus:** `pdf_url` uueneb, staatus läheb `korrektuuris` (korrektor saab uuesti üle lugeda)

### Korrektor: readonly split-view koos ettepanekutega

**Kes:** Korrektor (reviewer)
**Millal:** Noot on `paranduses` staatuses
**Tahan:** Näha readonly split-view vaadet (küljendus vs algnoot) koos oma eelmise korrektuuris tehtud parandusettepanekutega
**Tulemus:** Saan jälgida, kas graafik on mu märkused arvesse võtnud
